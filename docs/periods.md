# GET /api/v1/periods

Introductions of the periods (aika) of the church year from Evankeliumikirja: Adventtiaika, Jouluaika, Paastonaikaa edeltävät sunnuntait, Paastonaika, Pääsiäisaika, Helluntaiaika and the special days.

```json
{
  "source": "Evankeliumikirja (2021)",
  "periods": [
    { "name": "Adventtiaika", "season": "Joulujakso", "description": "Ensimmäisestä adventtisunnuntaista alkaa uusi kirkkovuosi. …" }
  ]
}
```
